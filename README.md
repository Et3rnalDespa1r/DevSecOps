# Инвентарь

Учебный проект по РБПО команды «Чайханчики».
Сервис для учёта выдачи и возврата вещей студенческого клуба.

К EK1 подготовлены Go-сервер, SQL-схема и учебные данные.
Маршрут `/healthz` проверяет соединение с PostgreSQL. Вход,
каталог, выдачи и возвраты описаны в концепции безопасности
и относятся к следующему этапу реализации.
