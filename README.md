# Инвентарь

Учебный проект по РБПО команды «Чайханчики».
Сервис для учёта выдачи и возврата вещей студенческого клуба.

Промежуточный этап S03: документы концепции. Техническая основа,
SQL и инструкция запуска добавляются в S05. Вход, каталог, выдачи
и возвраты относятся к последующей реализации продукта.
